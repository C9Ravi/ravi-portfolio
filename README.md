# Ravi Singh — 3D Portfolio

This repository contains the source code for the personal 3D portfolio of **Ravi Singh**, built with React, TypeScript, Three.js, React Three Fiber, and GSAP.

The portfolio features interactive 3D elements, animated sections, a custom cursor, smooth transitions, technology showcase, projects, experience, and contact information.

## Tech Stack

- React
- TypeScript
- Three.js
- React Three Fiber
- GSAP
- Vite
